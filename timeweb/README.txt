WETER — WEB VERSION FOR ORDINARY TIMEWEB PHP 8.2

Upload the contents of this folder to the site's web directory (for example public_html/weter/).

Open:
https://drinkandbloom.ru/weter/

Requirements:
- PHP 8.2+
- cURL extension enabled
- outbound HTTPS requests allowed (Open-Meteo)

No Python, Composer, Node.js, Uvicorn or server daemon is required.

The application uses index.php and the core1.php/core2.php/core3.php files only.
